# 개발 현황

`/implement-wi`가 WI를 착수·완료할 때 이 표를 갱신한다. 검토 상태(승인 여부)는 `docs/master/workitem-index.csv`의 상태 열이 따로 관리하며, 이 문서는 구현 진행만 다룬다.

**상태 값**: 대기 → 개발 중 → 개발 완료 / 보류(사유)

**개발 순서 원칙**: Wave(W0 → W1 → W2 → W3) 순서로 착수하고, 같은 Wave 안에서는 각 WI의 `선행`이 모두 `개발 완료`인 것부터 착수한다. W0(CMN-00 기반 26건)이 끝나기 전에는 QMS 메뉴 WI를 착수하지 않는다.
