# P16 PMS 수행·산출물·투입·비용

액티비티를 실제로 수행하는 단계다. 산출물 5종 등록과 팀장 필수 결재, 완료 조건(필수 데이터·산출물·QMS 조건) 검증과 자동 종료, 진척률·RAG와 Gantt 화면, 주간 투입 실적과 PM 일괄 승인, ED&D 임율·비용 계획·실적이 붙는다. 명세는 [Vol.P3](../10-workitems/volp3-pms05-06-cost-deliverable.md)·[Vol.P2](../10-workitems/volp2-pms04-07-schedule-activity.md)·[Vol.P1](../10-workitems/volp1-pms02-03-project-resource.md)이다.

## 3. 레인별 작업

### 레인 A — 산출물·완료(DLV-001 → DLV-002, ACT-004 → WBS-009, DLV-005)

1. **DLV-001**: 실행 산출물(유형 5종 — 파일·리비전·링크·시스템 링크·N/A, 일괄 등록), `syncFromTemplate`(P15 WBS-003·ACT-002·003에서 호출), 상태 자동 전이, 액티비티 롤업 6개, 시스템 링크 리졸버 구조(`PMS_SystemLinkType__mdt`). **Vol.0 선반영**: DOC-001 문서 부모 리스너·다중 부모 등록(V0-1·2).
2. **DLV-002**: 팀장 필수 결재(DP3-7: 기안자 소속 부서장, 부서장이면 상위), 유형별 PROJECT_ROLE 합의, 승인본 품번 게시(DP3-9 — QMS Re-PPAP 증빙 수집기가 읽음, V0-3), `PMS_DeliverableEvent__e`(DP3-10, 신설 권고). **Vol.0 선반영**: APV-001 하위 객체 공유(V0-5), DRAFTER_MANAGER(V0-6), 일괄 결재 상태(V0-4).
3. **ACT-004**: 완료 조건 검사기 등록부(키 + 파라미터, WBS-002), 필수 데이터·산출물(`PMS_DLV_MANDATORY_DONE` — Vol.P3 명칭으로 통일, Vol.P2는 `DLV_MANDATORY_DONE`)·QMS 조건 키(`QMS_LELE_NO_OPEN_MANDATORY`, `QMS_QUAL_PASS` — 구현체는 P17 INT-005, 지금은 미등록 시 "조건 확인 불가 → 수동 확인" 경로), 자동 종료·재시작·강제 완료(DP2-6·7), Gate 마일스톤은 Gate 결재로만 종료.
4. **WBS-009**: 과제 종료 승인(DP2-11: 정상 = PM 팀장, 임의 = PMO 합의 추가), SOP 초과 알림.
5. **DLV-005**: 산출물 검색·표준 양식 내려받기. 통합 검색 범위 등록(BR-6)은 A0에서 배포한 `CMN_SearchScope__mdt`로 먼저 하고, 문서 내용 색인·요약은 AI-002(QMS 트랙 P12) 완료 후 확인한다(연결 확인 L-1, [개발 플랜](dev-plan.md) 4.3절).

### 레인 B — 진척·화면·실적(WBS-007 → WBS-008, EFF-002)

1. **WBS-007**: 진척 산식(템플릿 속성: 수기·산출물 완료율·0/100, DP2-12), 기준선 대비 예상 진척·SPI, RAG.
2. **WBS-008**: 일정 Viewer(Gantt·CPM·Milestone 세 보기, 데이터 API 하나). 렌더러는 P15에서 정한 D-P2·DP2-3 결과.
3. **EFF-002**: 주간 실적 입력(한 화면에 참여 프로젝트 전부, 요일별), 제출 → PM 일괄 승인(DP1-6, 결재 엔진 미사용), PM 본인 실적은 공동 PM 또는 자동 확정, 상한 차단.

### 레인 C — 비용(CST-003 → CST-001 → CST-002)

1. **CST-003**: 직급 평균 임율(`PMS_LaborRate__c` — 재무만 원문), 임율 엔진 한곳(다른 WI 직접 조회 금지), 비용 권한 분리(PS 7종·Custom Permission `PMS_ViewCost` 등 — Vol.P3 3절), Snowflake 마스킹 `MP_PMS_COST`(V0-10).
2. **CST-001**: 예산 5범주(Tooling·ED&D·Piece Price·출장비·예비비, DP3-5), ED&D 자동 산정(계획 시간 × 임율), 기준선 확정. 통화는 금액 + 통화 코드(D-P5, D-3 전).
3. **CST-002**: ED&D 실적(승인 실적만, 월 귀속, 익월 5일 마감·동결, 조정 행 — DP3-3), 출장비 수동(DP3-15), DMS 수신 계약 자리(P20 INT-003).
