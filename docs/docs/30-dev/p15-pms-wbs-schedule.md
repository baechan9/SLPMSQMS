# P15 PMS 실행 WBS·일정 엔진·액티비티

표준 WBS와 시작일·고객 마일스톤으로 실행 WBS를 만들고, CPM 일정 엔진으로 예상 일정·여유·Critical Path를 계산해 일정을 결재로 확정한다. 액티비티 레코드·편집·복사·담당 변경과 CFT 할당 승인, 투입 계획이 여기서 붙는다. PMS에서 가장 큰 Fit-Gap(일정 엔진, PoC 시나리오 1·2)이 이 페이즈다. 명세는 [Vol.P2](../10-workitems/volp2-pms04-07-schedule-activity.md)와 [Vol.P1](../10-workitems/volp1-pms02-03-project-resource.md)이다.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목표 | 실행 WBS 자동 생성(고객 마일스톤 고정) → CPM 계산(선후행 4종·지연일·여유) → 일정 확정 결재·기준선·To-Do → 변경 요청·영향 시뮬레이션, 액티비티 화면·트리 편집·프로젝트 복사, CFT 팀장 승인, 주별 투입 계획(상한 경고) |
| 기간(기본 인원) | 누적 약 96영업일(P14 이후 약 26일) |
| 마일스톤 | 실행 WBS·CPM → 일정 확정·To-Do. PoC 시나리오 1(시작일·마일스톤으로 일정 자동 세팅)·2(고객 마일스톤 변경 영향) |
| 착수 조건 | P14 WBS-001·002, PRJ-001·003, CFT-001 `개발 완료` |
| 다음 페이즈로 당겨 착수 가능 | P16 중 DLV-001(WBS-003·ACT-001 뒤), CST-003(CFT-001 뒤) |

## 3. 레인별 작업

### 레인 A — 일정 엔진(ACT-001 → WBS-004 → WBS-003 → WBS-005 → WBS-006)

PMS 트랙 임계 경로다. 레인 A를 가장 먼저 착수한다.

1. **ACT-001**: `PMS_Activity__c`(주/보조 담당, 프로세스 속성 — BPA 연계 전에는 표준 WBS 값 복사), 레코드 화면(UX-004 생성기, 현재 단계 탭에 산출물 패널 자리 — Vol.P3 요청), 롤업 필드 자리.
2. **WBS-004**: Apex CPM(DP2-1: 순수 계산 클래스, Queueable, 바뀐 행만 저장, 프로젝트당 2,000 액티비티 상한, 임계 = 여유 ≤ 0, 경고 = 여유 ≤ 1일). **근무 달력**: Vol.0 변경 요청(MDM-002 확장 — 공장 근무 달력 객체, DP2-2). 결정 전에는 주말만 비근무로 보는 기본 달력으로 개발하고 달력 서비스 인터페이스 뒤에 숨긴다.
3. **WBS-003**: 실행 WBS 생성(표준 판 복사, 시작일·고객 마일스톤 앵커, 담당 역할 → 사람 해석). 마지막 단계에서 P16 `PMS_DeliverableService.syncFromTemplate`을 부를 자리(Vol.P3 요청)는 인터페이스로 두고 P16에서 연결. `PMS_CustomerMilestone__c.Activity__c` Lookup 생성(Vol.P1 계약 변경 6).
4. **WBS-005**: 일정 확정 결재(DP2-5: PM → PM 소속 팀장, PMO 참조), 기준선, CFT 알림, To-Do(다가오는 담당 액티비티). **명세 정합**: 확정 시 프로젝트 상태 PLANNING → IN_PROGRESS(Vol.P1 요청, Vol.P2 미반영), `PMS_ProjectEvent__e` SCHEDULE_CONFIRMED(Vol.P6 INT-005가 구독).
5. **WBS-006**: 변경 요청·영향 시뮬레이션(CP·Gate·고객 마일스톤), PM 즉시 적용 vs 결재(DP2-4), 이력.

### 레인 B — 액티비티 편집(ACT-002, ACT-003, ACT-005)

1. **ACT-002**: 트리 편집(레벨 이동·추가·삭제·취소), 필수 액티비티 보호, 확정 후 일정 영향 편집은 WBS-006 변경 요청으로 보냄. 그리드는 UX-006(텍스트 부모 필드 지원 — Vol.P4 변경 요청과 같음).
2. **ACT-003**: 프로젝트 복사(WBS·CFT, 실적·이력 제외).
3. **ACT-005**: 담당자 변경 요청·일괄 변경(완료 액티비티 제외).

### 레인 C — 자원(CFT-002 → EFF-001)

1. **CFT-002**: 역할 단위 할당 요청 → 팀장 "CFT 요청함"에서 사람 지정·승인(DP1-5, 구성원 1명당 결재 1건), 중도 교체·해제(미완료 담당 있으면 해제 불가).
2. **EFF-001**: 사용자 × 프로젝트 × 주 1행(DP1-7, D-P4), 액티비티 기여율·기본 배정에서 자동 계산, 일정 변경 시 재계산, 상한(일 8시간·주 52시간 차단, 주 40시간 경고 — DP1-8, 공장별 정책 `PMS_WorkHourPolicy__mdt`). CFT 후보 여유율(P14 CFT-001)이 이때부터 채워진다.
