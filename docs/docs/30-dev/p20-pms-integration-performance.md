# P20 PMS 외부 연계·성과·변경

프로세스 포탈(BPA)·HR·DMS·부품개발시스템·PDM·ALM 연계와 협력사 부품개발 일정, SOP + 2개월 성과 평가·수평평가, 프로젝트 변경 대장(비용·범위 변경)과 DMS 수정비·부품개발 비용 단계 적용을 만든다. 모두 W2·W3이며 P17 INT-005의 연결 대장·핸들러 등록부(DP6-1)를 재사용한다. Mule 흐름은 외부 트랙, Salesforce 쪽은 계약 CSV upsert로 확인한다. 명세는 [Vol.P6](../10-workitems/volp6-pms12-13-integration-performance.md)·[Vol.P2](../10-workitems/volp2-pms04-07-schedule-activity.md)다.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목표 | 표준 WBS ↔ BPA 속성 대조·변경 검토, HR 임율 수신·수평평가 전송, DMS 비용 실적·수정비 수신, 부품개발 일정·PDM 도면·ALM 마일스톤 연결과 지연·개정 알림, 성과 지표 자동 채움(양산 초기 NCR·클레임), 수평평가(비공개), 변경 대장 |
| 기간(기본 인원) | 처음부터 약 165영업일(P17 연결 대장 뒤, P19 AI와 병렬) |
| 마일스톤 | 외부 연계 계약 확인(L1), SOP + 2개월 성과 |
| 착수 조건 | P17 INT-005(연결 대장), P16 CST-002·003, P15 WBS-004, P17 GAT-004 |

## 3. 레인별 작업

### 레인 A — 외부 연계(INT-001 → INT-004 → INT-003 → INT-002)

인터페이스 ID는 Vol.P6 기준(IF-BPA-001, IF-HR-002·003, IF-DMS-001·002, IF-PDM-001·002, IF-ALM-001~004, IF-PDS-004·005 — Vol.9가 IF-PDS-001~003을 이미 씀).

1. **INT-001**: BPA 프로세스·액티비티 속성 수신 → 표준 WBS 대조 → PMO 변경 검토(DP6-13). 회사표준 개정(26.11~27.04) 반영 경로.
2. **INT-004**: 부품개발시스템 협력사 일정(WBS-010과 함께), PDM 도면·BOM 리졸버(P16 DLV-001 시스템 링크 유형 교체), ALM(Codebeamer) 마일스톤·요구사항(DP6-14, ALM이 소프트웨어 요구사항 원본 — DP1-14).
3. **INT-003**: DMS 금형·지그·검사구·제비용 → `PMS_CostActual__c`(인식 기준 DP6-7), 금형 수정 건 → 변경 대장(CHG-002).
4. **INT-002**: HR 임율 upsert(ExternalKey `{CompanyCode}-{JobGradeCode}-{Year}`, DP6-6), 수평평가 결과 전송(집계·익명 기본 — DP6-4).

### 레인 B — 협력사 일정·성과·변경(WBS-010, PRF-001 → PRF-002, CHG-001 → CHG-002)

1. **WBS-010**: 협력사 부품개발 일정을 프로젝트 WBS와 같은 화면에, 협력사 지연이 SL Critical Path를 밀 때 경고.
2. **PRF-001**: SOP + 2개월 성과(일정 준수율·비용 초과율·Gate 이력·양산 초기 NCR·클레임 수 — 연결 대장 기준, DP6-11. `CMN_KpiValue__c`는 품번별 분리가 안 됨).
3. **PRF-002**: PM·CFT 수평평가(평가자·HR만 열람). **DP6-3**: `PMS_PeerEvaluation__c`를 Master-Detail에서 Lookup + OWD Private로(Master-Detail이면 프로젝트 공유로 서로의 평가가 보임). 평가 범위 DP6-5.
4. **CHG-001**: 프로젝트 변경 대장(일정·담당·산출물 변경은 각 기능 결과 기록, 비용·범위 변경은 여기서 요청·영향·결재·적용 — DP6-9), 비용 변경 승인 시 `PMS_CostPlanService.confirmBaseline` 재확정.
5. **CHG-002**(W3): DMS 수정비 원인·책임·청구 분류, 부품개발 비용 단계별 계획·집행(DP6-8).
