## 2. 구현 내역

- **표준 레코드 페이지:**
  - 데스크톱 템플릿은 `flexipage:recordHomeWithSubheaderTemplateDesktop`(헤더, 하위 헤더, 오른쪽 사이드바)이다.
    - A 헤더: 하이라이트 패널
    - B 하위 헤더: `cmnStatusPath` + `cmnDueIndicator`
    - C 본문: 탭 4개(현재 단계 기본 선택 / 상세 / 관련 / 이력)와 Dynamic Forms 필드 섹션
    - D 사이드바: `cmnDecisionRail` 하나
  - 휴대폰 템플릿은 `flexipage:recordHomeTemplateDesktop`이다. 본문은 진행 단계·기한·탭(현재 단계 / 상세)이고, 사이드바의 레일이 본문 아래에 보인다.
  - 탭·섹션 제목은 Custom Label(`{!$Label.이름}`)이다.
- **생성 도구:**
  - `scripts/dev/record-page.py`: 정의 `meta-src/*/record-pages/{객체}.json` → FlexiPage 2개를 처음 한 번 만든다. 이미 있으면 건너뛰고 `--force`일 때만 덮어쓴다.
  - `metagen.py` 확장:
    - 같은 정의로 헤더 콤팩트 레이아웃 `{객체}_Header`(7개 초과면 중단)를 만들고 객체에 지정한다.
    - 폼 팩터별 기본 보기를 지정한다(`recordPage`가 {Large, Small}).
    - 생성 파일 종류에 `compactLayout`을 더했다.
- **CI 검사:**
  - `scripts/ci/check-record-pages.py`: 하이라이트 패널, 진행 단계, 사이드바에 레일 하나, 첫 탭 "현재 단계"·기본 선택, 첫 탭 10개 이하, 관련 목록 3개 이하, 휴대폰 레일, 기본 보기 지정.
  - `scripts/ci/check-lwc-styling.py`: 색 리터럴, `--slds-c-*`, `--lwc-*`.
  - 두 검사를 `ci.yml`과 `wi-check.sh`에 넣었다.
- **Custom Metadata:**
  - `CMN_RailPanel__mdt`(필드 10개).
  - 기본 패널 5종(`*`): AI(비활성), 결재(펼침), 할 일, 코멘트, 문서.
  - 테스트 객체 행: 결재 유형 `CMN_TEST_APPROVE`, 문맥 분석 `cmnWidgetTodoSummary`(bind plantId = Plant__c).

    - `getPanels`(cacheable): 병합·거르기·정렬.
    - `resolveBindings`: 최대 10개 필드, describe 검증, USER_MODE.
    - `getOpenTodos`(cacheable): 레코드의 원천·대상 To-Do 20건, 받는 사람 언어 제목.
  - `CMN_RailPanelSelector`.
