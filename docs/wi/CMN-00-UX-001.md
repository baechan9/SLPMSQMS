## 2. 구현 내역

- LWC
  - `cmnImageResize`(서비스 모듈): `fitWithin`(장변 1920px, 비율 유지), `resizeImage`(캔버스 JPEG 0.85), `jpegName`.
  - `cmnPhotoCapture`(레코드 페이지, 속성 docClass 기본 NCR_PHOTO): 카메라 촬영·파일 선택, 최대 10장, 축소 후 `CMN_PhotoController.uploadPhotos`, `uploaded` 이벤트.
  - `cmnBarcodeScanner`(공통 하위 컴포넌트): 모바일 앱이면 `lightning/mobileCapabilities` BarcodeScanner(QR·Code128·Code39·EAN13·DataMatrix), 웹이면 수동 입력. `scan` 이벤트(value, type). 사원증 사번 수동·스캔 공통.
- Apex `CMN_PhotoController`: 사진(base64, 최대 10장·장당 4MB 이하, 파일명 검증)을 사용자 파일로 저장 → `CMN_DocumentService.registerFiles`(DOC-001)로 문서 등록. `CMN_PS_Document_User`에 클래스 접근 추가.
- 라벨 7개(ko·en_US·zh_CN).
- 데모 코드 시드: DOC_CLASS 속성 열(Attribute1~3) — 사진 분류(IQC·NCR·한도견본·시험·한도견본 점검·실험 이미지) MULTI_FILE, PPAP 설계 기록 LINK_ONLY(도면).
- 점검: `scripts/ci/check-lwc-mobile.py`(wi-check·GitHub CI).
- 앱: SL QMS·SL PMS는 이미 Small·Large 폼팩터(SEC-001).
