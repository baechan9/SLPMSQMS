## 2. 구현 내역

- **객체** `CMN_ScreenGuide__c`:
  - 필드: PageKey, Language(6종), Content(서식 있는 텍스트), VideoUrl, StandardDocUrl, IsPublished, ExternalKey(유일, 서비스 전용).
  - 공유: 사내 공개 읽기 전용, 외부 비공개.
  - 목록: "전체", "미게시".
- **Apex:**
  - `CMN_ScreenGuideService`: 화면 키 형식 확인, 외부 키 채움.
  - 트리거·핸들러.
  - `CMN_ScreenGuideController.getGuide(pageKey, recordId)`: cacheable. 게시된 가이드를 사용자 언어 → en_US → ko 순으로 찾는다. 사용자 권한으로 읽는다.
- **LWC** `cmnScreenGuide`(유틸리티 바):
  - CurrentPageReference로 화면 키를 정한다.
  - 표시: 제목, 언어 대체 안내, 본문, 동영상·회사표준 링크(새 창), 고친 날, 화면 키(관리자가 가이드를 등록할 때 참고).
  - 상태: 없음, 대상 아님, 오류.
  - 화면을 빨리 옮겨 다녀도 마지막 화면 결과만 보인다.
- **화면 배치:**
  - 유틸리티 바 `SL_UtilityBar`에 "Guide"를 더했다. 모든 SL 앱이 이 바를 쓴다.
  - SL Admin 앱에 "화면 가이드" 탭을 더했다.
- **권한 셋:**
  - `CMN_PS_ScreenGuide_Read`: 읽기와 컨트롤러. 사내 PSG 14개에 넣었다.
  - `CMN_PS_ScreenGuide_Admin`: 작성·삭제·모두 수정과 탭. SystemAdmin과 QualityAdmin에 넣었다.
- **샘플** `scripts/apex/seed-screen-guides.apex`: QMS 홈·메뉴 허브·통합 검색·샘플 업무 레코드 가이드 5건(영어 1건 포함). 외부 키로 upsert한다.
- **라벨** 9개(ko·en_US·zh_CN).
