## 2. 구현 내역

- **앱(표준 내비게이션, 콘솔 미사용 DS-7):**

  | 앱 | 내비게이션 |
  | --- | --- |
  | 새 앱 `SL_QMS_Quality`(SL QMS 품질 업무) | 홈, 메뉴 허브 |
  | 새 앱 `SL_QMS_Field`(SL QMS 현장) | 현장 홈 |
  | `SL_QMS` | 13개 → 4개(홈, 결재 현황, 내 대시보드, 메뉴 허브) |
  | `SL_Admin` | 21개 → 6개(메뉴 허브, 공통 코드, 결재 템플릿, 연계 로그, 로그, 삭제 로그) |
  | `SL_PMS` | 공통 업무·기준정보 허브 탭 → 메뉴 허브 |

  - 품질 업무 앱의 업무 탭(NCR, 클레임·8D, 4M 변경, 검사, 인정시험, 개선과제)은 각 화면 묶음이 화면을 만들 때 넣는다.
  - 메뉴별 허브 탭(QMS_Menu02~09, CMN_MenuWork, CMN_MenuMaster)은 내비게이션에서 뺐다. 탭은 남겨 두고, 메뉴 허브 그룹 머리글의 "메뉴 열기"로 연다.
- **앱 페이지·탭:**
  - `CMN_MenuHub`(전체 메뉴 허브, `cmnAppMenuHub` menuKey 없음). 모든 앱이 같은 탭을 쓴다.
  - `CMN_QMS_FieldHome`(현장 홈, `cmnTodoList`만).
- **Custom Metadata:**
  - `CMN_AppMenu__mdt` 필드 추가: `Apps__c`, `PageTab__c`. 레코드 10건을 채웠다.
    - QMS-02~09: 품질 업무·SL QMS
    - 공통 업무: 품질 업무·SL QMS·Admin·PMS
    - 기준정보: 품질 업무·Admin·PMS
  - `CMN_AppMenuItem__mdt` 필드 추가: `RequiredPermission__c`, `TodoSourceTypes__c`, `KeywordsLabel__c`, `ShowOnPhone__c`. 레코드 68건에 반영했다.
    - 배지: To-Do `*`, 결재 현황 `CMN_APPROVAL`, 조치 항목 `CMN_ACTION_ITEM`.
    - 휴대폰 표시 타일 12개.
    - 검색 동의어 4개(결재, To-Do, 부적합, 수입검사).
  - 소유 WI를 `A0-PROTO-KIT`에서 `CMN-00-UX-007`로 바꿨다.
- **Apex:**
  - `CMN_AppMenuController`:
    - `getHub(appName, formFactor)`: 앱별 그룹, 빈 그룹 숨김, 배지, 휴대폰 타일, 번호 접두어.
    - `findRecord(recordNo)`: 채번 규칙에서 가장 긴 접두어 → 객체·번호 필드를 검증한 뒤 USER_MODE 조회. 없음과 권한 없음은 같은 답이다.
    - `getMenu`에도 배지와 페이지 권한을 반영했다.
  - `CMN_AppMenuSelector`: 활성 메뉴 전체, 여러 메뉴 타일 일괄 조회, 현재 앱(`UserAppInfo`→`AppDefinition`, USER_MODE), 내 열린 To-Do 집계 2회(USER_MODE), 채번 규칙.
- **LWC:** `cmnAppMenuHub`
  - menuKey가 없으면 전체 메뉴 모드다: 검색창(화면 이름·동의어 필터, 업무 번호 + Enter → 레코드), 그룹 바로가기, 그룹 머리글(메뉴 열기), 미결·기한 경과 배지(텍스트+아이콘), 새로 고침.
  - 설계 속성 `appName`(앱 고정, 선택)을 더했다.
- **권한:**
  - 새 권한 세트 `CMN_PS_AppQmsQuality_Read`(앱, 메뉴 허브·홈·내 대시보드 탭, 컨트롤러)와 `CMN_PS_AppQmsField_Read`(앱, 현장 홈 탭)를 만들었다.
  - 기존 앱 권한 세트 3개에 메뉴 허브 탭을 더했다. Admin 앱 권한 세트에는 공통 업무·기준정보 허브 탭과 컨트롤러도 더했다.
  - PSG 할당(BR-1):
    - 품질 업무 앱: 전문가 8개 + 품질경영팀 + 시스템 관리자
    - 현장 앱: SQE·시험·측정기·심사원·검사원 + 시스템 관리자
- **라벨(ko·en_US·zh_CN):** 16개를 더했다(허브 제목·설명, 검색, 찾을 수 없음, 검색 결과 없음, 메뉴 열기, 미결, 기한 경과, 새로 고침, 바로가기, 검색 동의어 4). 앱 2개·탭 2개 번역도 함께 넣었다.
- **설계 판단:**
  - (1) 현재 앱은 `UserAppInfo`로 판별한다. 앱을 바꾼 적 없는 사용자는 기록이 없으므로 프로필 기본 앱 `SL_QMS`로 본다. 페이지가 앱을 고정할 수 있게 설계 속성 `appName`을 뒀다.
  - (2) 배지는 허브를 열 때 한 번 센다(실시간 갱신 없음, 새로 고침 버튼).
  - (3) 번호 접두어 목록을 화면에 내려, 접두어로 시작하지 않는 검색어는 서버를 부르지 않는다.

## 4. 보안·성능 점검

- [x] USER_MODE 조회(To-Do 집계, 앱 판별, 번호 조회), 메타데이터는 SYSTEM_MODE 명시, `without sharing` 없음
- [x] 서버 입력 검증: 메뉴 키·앱 이름·화면 크기·업무 번호 형식. 사용자 메시지는 라벨, 원문은 CMN_Logger
- [x] 동적 SOQL은 객체·필드 이름을 describe로 검증하고 `escapeSingleQuotes`, 값은 바인드
- [x] 번호 바로가기는 없음과 권한 없음을 같은 메시지로 답함(존재 여부 노출 없음)
- [x] 루프 안 SOQL·DML 없음, 하드코딩 Id 없음(To-Do 상태는 `CMN_TodoService.OPEN`)
